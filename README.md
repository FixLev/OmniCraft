# OmniWars — первый набросок (v0.2)

Rust + wgpu (бэкенд Vulkan) + egui. Без игровых движков.

## Сборка
1. Установи Rust: https://rustup.rs  (+ Visual Studio Build Tools, компонент «Разработка классических приложений на C++»)
2. В этой папке: `cargo run --release`
3. Готовый файл: `target\release\omniwars.exe`

## Управление (как в Minecraft)
- WASD — движение, Space — прыжок, мышь — обзор
- Ctrl или двойное нажатие W — бег
- Shift — присед (не даёт упасть с края блока)
- Двойное нажатие Space — полёт (Space вверх, Shift вниз, Ctrl — быстрее)
- ЛКМ — ломать, ПКМ — ставить, Esc — пауза

## Физика
Фиксированные 20 тиков/с, константы ванильные: ходьба 0.1, бег ×1.3, присед ×0.3,
ввод ×0.98, трение 0.6×0.91 / 0.91, гравитация 0.08, сопротивление 0.98,
прыжок 0.42 (+0.2 вперёд при беге), задержка прыжка 10 тиков, хитбокс 0.6×1.8 (присед 1.5).
Между тиками позиция, FOV и высота глаз интерполируются, поэтому картинка плавная при любом FPS.
